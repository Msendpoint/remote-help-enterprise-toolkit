# Remote Help Enterprise Management Toolkit

> A comprehensive automation suite for deploying, auditing, and monitoring Microsoft Intune Remote Help sessions within an enterprise environment.

## Overview

This PowerShell project was extracted from an article on [MSEndpoint.com](https://msendpoint.com) and is part of the professional automation portfolio.

### Quick Start

```powershell
# Clone the repository
git clone https://github.com/Msendpoint/remote-help-enterprise-toolkit.git
cd remote-help-enterprise-toolkit

# One-click install & run (checks prerequisites, installs modules, launches main script)
.\Install.ps1
```

## Tech Stack

PowerShell, Microsoft Graph, PHP

## Requirements

- PowerShell 7.0 or later
- Microsoft Graph CLI (if applicable)
- Appropriate administrative permissions
